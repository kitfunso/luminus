# v0.4.2 Release Notes

Released: 2026-04-07

Corrected UK/GB naming throughout the MCP server. Northern Ireland is part of the UK but not part of the GB electricity network (it uses the all-island Irish grid with Ireland). All tool names, profiles, and display labels that previously said "UK" now correctly say "GB" where the data covers Great Britain only.

## Breaking changes

- `get_uk_carbon_intensity` renamed to `get_gb_carbon_intensity`
- `get_uk_grid_demand` renamed to `get_gb_grid_demand`
- `--profile uk` renamed to `--profile gb`

## Other changes

- Display labels changed from "United Kingdom" to "Great Britain" for electricity grid data
- Source files renamed: `uk-carbon.ts` / `uk-grid.ts` to `gb-carbon.ts` / `gb-grid.ts`
- Company names (UK Power Networks / UKPN), URLs, and market names (UK NBP) unchanged

## Versions

- `luminus-mcp@0.4.2`
- `luminus-py==0.4.1` (unchanged)
