# v0.4.3 Release Notes

Released: 2026-04-16

Patch release fixing ENTSO-E intraday price queries. The `get_intraday_prices` tool was sending the wrong document type and process type parameters (`A67`/`A01` instead of `A44`/`A18`), causing ENTSO-E to return an invalid-combination error instead of intraday price data.

## Fixed

- `get_intraday_prices`: corrected `documentType` from `A67` to `A44` and `processType` from `A01` to `A18` (contributed by @antondelorme in #14)

## Versions

- `luminus-mcp@0.4.3`
- `luminus-py==0.4.1` (unchanged)
