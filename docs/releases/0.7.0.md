# v0.7.0 Release Notes

Released: 2026-08-09

ENTSO-E imbalance-data correctness release. An external report (issue #21) made seven findings against the imbalance tooling; every one checked out. Four parser/query defects are fixed and verified against the live ENTSO-E API, and a new authoritative German data source covers the rest.

## What's fixed

### get_imbalance_prices returned volumes labeled as prices

The tool queried ENTSO-E documentType A86, which is imbalance VOLUME, and read `Point.quantity` as if it were a EUR/MWh price. That is why it "worked" silently: a volume number filled the price field on every row. It now queries A85 (imbalance prices) and reads only price keys (`imbalance_Price.amount` / `price.amount`). A quantity is never read as a price; a point with no price key is skipped, not coerced to 0.

Verified two ways: the entsoe-py reference client's source (A85 = "Imbalance prices", A86 = "Imbalance volume") and a live DE query returning plausible EUR/MWh values.

### ZIP responses failed to parse

ENTSO-E's imbalance endpoints can return a ZIP archive of XML documents instead of plain XML. The client assumed plain XML and choked. `queryEntsoe` now detects ZIP by magic bytes (content-type is unreliable) and merges multi-file archives' TimeSeries under one document root. Fixed at the transport layer, so every ENTSO-E tool benefits.

### Balancing_MarketDocument responses were missed

A85/A86 responses arrive under the `Balancing_MarketDocument` root. The XML parser already listed it as a known array path, but no tool ever checked it, so valid data read as "no data returned." Both price tools check it first now.

### A03 step curves returned fewer than 96 rows

ENTSO-E step curves (curveType A03) omit a point when its value repeats the previous position. Reading only explicit points under-reported the day. A shared extraction helper now expands each period to its full slot count from timeInterval/resolution and forward-fills the gaps. Two subtleties handled: the fill carries across period boundaries within one TimeSeries (a step can span midnight-adjacent periods) but never across different series, and period numbers are anchored to timestamps so overlapping price-category series share numbers 1-96 instead of stacking to 192.

### Housekeeping

- `processType` dropped from A85 queries; the reference client sends `documentType` + `controlArea_Domain` only.
- Lockfile-only bumps past the hono / ip-address / qs advisories that accumulated since June (transitives of `@modelcontextprotocol/sdk`). `npm audit` clean.

## What's new

### Full German imbalance data via netztransparenz.de

ENTSO-E has no German imbalance price before 2022-09-30, and its per-TSO German volumes have historic control-area gaps, so summing them undercounts. The authoritative series are reBAP (uniform German imbalance price) and NRV-Saldo (grid control cooperation system imbalance), published on the German TSOs' transparency platform.

- `get_imbalance_prices` for DE now falls back to reBAP when ENTSO-E returns nothing. Results carry a new additive `source` field (`"entsoe"` / `"netztransparenz_rebap"`) so provenance is always explicit.
- New tool `get_german_system_imbalance` serves NRV-Saldo in MW per quarter-hour.
- Credentials: register free at [netztransparenz.de/en/Web-API](https://www.netztransparenz.de/en/Web-API), then set `NETZTRANSPARENZ_CLIENT_ID` and `NETZTRANSPARENZ_CLIENT_SECRET` as environment variables or in `~/.luminus/keys.json`. Without credentials, non-DE behavior is unchanged and a DE failure names the registration path.

The endpoint shape was verified against two working open-source clients of the API; a live call is pending credentials.

## Verification

- 423 JS tests passing (was 400 at 0.6.1). The 23 new tests cover the A85 parameter, ZIP single/multi-file handling, step-curve expansion, series-boundary fill, overlapping-series numbering, German CSV parsing (semicolon separator, decimal comma), and the DE fallback on/off paths.
- Live E2E against ENTSO-E: DE 2026-08-08 returns both price-category series correctly sharing quarter-hour periods 1-96.
- TypeScript build clean; CI green on every release commit.

Thanks to the issue #21 reporter for a report where all seven findings were real.
